# 한국어 발표 말투 묶음

`coaching.md`의 공통 규칙을 한국어 발표에 맞춘 것이다. 예는 실제 본선 준비에서 걸린 문장이다.

## 끝맺음과 자신감

| 규칙 | 틀린 예 | 맞는 예 |
|---|---|---|
| 끝은 "~습니다"로 맺는다. "~는데요"로 흐리지 않는다. 주제를 여는 말("빼놓을 수 없는데요")은 괜찮다 | "이어 가기도 매우 어려운데요" | "이어 가기도 어렵습니다" |
| "해 보겠습니다"는 자신 없게 들린다 | "발표해 보겠습니다" | "발표하겠습니다" |
| 효과를 단정하지 않는다 | "아동이 스스로 해냅니다" | "스스로 해낼 수 있게 돕습니다" |
| 미완성으로 들리는 말을 쓰지 않는다 | "개발 중에 있습니다", "생각을 해 봤는데요" | "세 가지입니다", "제공합니다" |
| 약점처럼 들리는 말을 쓰지 않는다 | "살짝 버그가 있어서", "고쳤습니다" | "이후 개선했습니다" |
| 사실 그대로 말한다 (기억·감상 꾸밈 빼기) | "칭찬을 해 주셨던 기억이 있습니다" | "칭찬해 주셨습니다" |

## 문장 길이와 연결

| 규칙 | 틀린 예 | 맞는 예 |
|---|---|---|
| 긍정과 부정을 한 문장에 넣지 않는다. "하지만"으로 새 문장 | "관심이 커지고 있지만 보호자는…" | "…커지고 있습니다. 하지만 보호자는…" |
| "~하고 ~하고 ~해서" 이어 붙이지 않는다. 마침표에서 끊는다 | "안내하고 그림과 음성을 보면서 따라 하게 됩니다" | "안내합니다. 아동은 그림을 보고 음성을 들으며 따라 합니다." |
| 감각과 동사를 맞춘다 | "그림과 음성을 보면서" | "그림을 보고 음성을 들으며" |
| 같은 말을 두 번 넣지 않는다 | "일과를 행동카드로 나눠 행동카드로" | "일과를 행동 단계로 나눠 행동카드로" |

## 군말

"뭐", "엄청", "어", "이제", "좀", "그런", "약간", "되게"는 뺀다. 사용자가 일부러 쓰는 말투(예: 주제를 여는 "~는데요")는 `memory.md`의 `## Voice`에 있으면 살린다.

## 용어 (예, 덱마다 `memory.md` Glossary가 정본)

| 쓰지 않는다 | 대신 | 이유 |
|---|---|---|
| 시연 | 실증 | 현장에서 실제로 써 본 것 |
| 고쳤다 | 개선했다 | 고쳤다는 틀렸다는 뜻으로 들린다 |
| 클릭 | 누릅니다 | 터치 화면 |

## 받아쓰기 오류 감안

음성 입력은 이름과 고유명사를 자주 틀린다("서세찬", "이름미"). 덱 `memory.md`의 `## Transcript fixes` 표에 들린 말과 실제 말을 적어 두면 녹화 받아쓰기에도 적용된다.
