📝 현재 문제점
---

- README의 데모가 GitHub 화면 캡처 5장을 2.8초씩 넘기는 슬라이드쇼 GIF다. 움직임이 없어 "무엇을 하면 무슨 일이 일어나는지"가 전달되지 않고, 화면 전체를 줄여 넣어 글자가 읽히지 않으며, 한 GIF에 여러 기능이 섞여 있다.
- 기능별로 한 가지 일만 보여 주는 영상이 없어 처음 온 사람이 각 기능이 무엇을 자동화하는지 이해하기 어렵다.

🛠️ 해결 방안 / 제안 기능
---

- 테스트 조직(`git-sandboxes`)에 임시 레포를 만들어 projectops를 실제로 설치하고, 기능 하나당 짧은 GIF 하나를 **실제로 실행하며 녹화**한다.
  1. 이슈를 열면 브랜치명과 커밋 메시지 템플릿 댓글이 달린다
  2. PR을 열면 변경 요약 댓글이 달린다
  3. 릴리스 PR이 버전 확정, 자동 머지, 태그 생성까지 진행된다
- 화면 구석에 실제 경과 시간 타이머를 표시하고 기다리는 구간만 빠르게 재생해, 연출이 아니라 실제 속도임을 보여 준다. 단계별 설명 바와 강조 표시를 붙인다.
- README와 문서 사이트의 슬라이드쇼를 이 GIF들로 교체한다.
