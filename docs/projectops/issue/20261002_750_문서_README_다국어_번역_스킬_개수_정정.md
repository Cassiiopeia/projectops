📝 현재 문제점
---

- README가 한국어 한 가지뿐이다. 이 도구는 npm(`npx projectops`)으로 배포되고 Claude Code, Gemini CLI, Codex CLI 사용자는 국적과 무관하다. 한국어를 읽지 못하는 방문자는 첫 화면에서 이탈한다.
- README의 "Agent Skills 17종"이 실제와 다르다. 실제 `SKILL.md`는 20개이고, 표에는 17개, 이전 세대 경로(`pro-plan`, `pro-analyze`, `pro-implement`) 3개가 따로 적혀 있다.
- `docs/SKILLS.md`에 `/pro-launch`와 `/pro-design-brief` 상세 항목이 없고, 구현형 그룹 개수(4종)도 실제 항목 수와 맞지 않는다.

🛠️ 해결 방안 / 제안 기능
---

- 영어, 중국어(간체), 일본어 README 번역본을 추가하고 README 상단에 언어 전환 링크를 둔다.
- 번역본은 `docs/i18n/`에 둔다. 루트에 두면 "Use this template"로 만든 새 프로젝트에 딸려 가므로, 복사에서 제외되는 `docs/` 아래에 둔다.
- 스킬 개수를 20종으로 바로잡고, `docs/SKILLS.md`에 빠진 두 스킬 항목과 그룹별 개수를 보강한다.

⚙️ 작업 내용
---

- `docs/i18n/README.en.md`, `README.zh-CN.md`, `README.ja.md` 신규 (정본은 한국어, 번역본 상단에 명시)
- `README.md`: 언어 전환 링크, 스킬 개수 정정
- `docs/SKILLS.md`, `docs/README.md`: 개수 정정, `/pro-launch`, `/pro-design-brief` 항목 추가
