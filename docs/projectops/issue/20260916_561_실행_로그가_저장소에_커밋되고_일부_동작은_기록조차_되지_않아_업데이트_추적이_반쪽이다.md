📝 현재 문제점
---

마법사는 실행할 때마다 기록 3계층을 남긴다. 그런데 **두는 자리가 잘못됐고, 담기는 내용이
반쪽이라 로그만으로 실행을 재구성할 수 없다.**

**1. 진단용 기록이 저장소에 커밋된다**

현재 위치는 `docs/projectops/migration/`이다. 문서 폴더 안이라 **git 추적 대상**이고
업데이트를 돌릴 때마다 커밋할 파일이 늘어난다.

이 기록은 사람이 읽는 문서가 아니라 **AI Agent가 "지난 실행에서 무슨 일이 있었나"를
확인하는 진단 자료**다. 저장소 이력에 남을 이유도, 팀원과 공유할 이유도 없다.

**2. 사람이 실행하고 선택한 과정이 전혀 남지 않는다**

가장 큰 공백이다. 마법사는 대화형으로 여러 질문을 하고 사용자가 답하는데, **그 질문과 답이
어디에도 기록되지 않는다.**

- 어떤 모드를 골랐는지
- 프로젝트 타입을 무엇으로 확정했는지
- 배포·publish 축에서 무엇을 선택했는지
- 충돌 파일마다 유지/백업/템플릿 중 무엇을 택했는지
- 호환성 경고를 보고 계속 진행했는지
- 환경값을 직접 입력했는지 기본값을 썼는지

나중에 "왜 이렇게 설치됐지?"를 물으면 **결과만 남아 있고 그 결과에 이른 경위가 없다.**
사람이 무엇을 보고 무엇을 골랐는지가 빠져 있어 재현도 설명도 불가능하다.

**3. 워크플로우 밖의 동작도 기록되지 않는다**

| 영역 | 기록 |
|---|---|
| 워크플로우 복사·충돌·치환 | ✅ 파일별로 전부 |
| 고아 정리 / 구 파일 무해화 / 설치 검증 | ✅ |
| **기준점 판정 근거** | ❌ "자동 갱신됨"만 있고 왜 그렇게 판정했는지 없음 |
| **스크립트·util·이슈템플릿 복사** | ❌ 아예 없음 |
| **프로젝트 성격 옵션** | ❌ 가이드 메타에 누락 |

Agent에게 "업데이트 로그 보고 정리해줘"라고 하면 워크플로우는 정확히 답하지만
**"내 스크립트가 바뀌었나"에는 답하지 못한다.**

**4. 터미널 기록이 사실상 비어 있다**

같은 실행에서 이벤트 기록은 9KB인데 터미널 미러는 **65바이트**, 배너 한 줄뿐이다.
캡처를 배너 직후 시작해 그 뒤 출력이 잡히지 않는다.

🛠️ 해결 방안 / 제안 기능
---

**1. 자리 이동 + 추적 제외**

```
.github/.projectops/
├── baseline.json     ← 커밋 유지 (팀원이 같은 기준점을 봐야 판정이 일관됨)
└── logs/             ← 추적 제외
    ├── PROJECTOPS-MIGRATION-GUIDE.md
    ├── {stamp}_v{from}_to_v{to}.jsonl
    └── {stamp}_v{from}_to_v{to}.log
```

같은 부모 아래 두되 **성격이 반대라 폴더를 나눈다.** 기준점은 공유 자산, 기록은 진단 자료다.
통합 시 추적 제외 항목을 자동 등록한다.

**구 경로는 처리하지 않는다.** 하위호환을 고려하지 않고 새 위치로 전환한다.

**2. 실행의 전 과정을 남긴다**

"마지막에 로그만 보고 전체를 출력할 수 있어야 한다"가 기준이다. 결과가 아니라 **경위**를 남긴다.

| 새 분류 | 남기는 것 |
|---|---|
| 실행 경계 | 시작(버전·모드·인자)·종료(결과·소요) |
| 단계 진행 | 각 단계 시작과 끝, 처리 건수 |
| 질문과 응답 | 무엇을 물었고 사용자가 무엇을 골랐는지 |
| 판정 근거 | 그 결정에 이른 이유 (기준점 일치 여부 등) |
| 복사 전 영역 | 워크플로우 외 스크립트·util·템플릿·설정 |

민감값은 기존 가드가 계속 걸러낸다 — 우회하지 않는다.

**3. 터미널 기록 정상화**

캡처를 진입 직후로 당기고 요약 출력까지 담는다. 색상 제어문자는 제거해 저장한다 —
이 파일의 소비자는 터미널이 아니라 나중에 읽는 사람과 Agent다.

**4. 실행 끝에 기록 위치를 알린다**

완료 화면에서 어디에 무엇이 남았는지 한 줄로 안내한다.

⚙️ 작업 내용
---

- 기록 위치 이동, 추적 제외 자동 등록 (구 경로 마이그레이션 없음)
- 실행 경계·단계 진행·질문과 응답·판정 근거 기록 추가
- 워크플로우 외 복사 영역 기록 추가
- 터미널 캡처 구간 교정 및 제어문자 제거
- 완료 화면에 기록 위치 안내
- 문서의 3계층 설명 갱신
- 기록 항목·위치·제외 회귀 테스트
