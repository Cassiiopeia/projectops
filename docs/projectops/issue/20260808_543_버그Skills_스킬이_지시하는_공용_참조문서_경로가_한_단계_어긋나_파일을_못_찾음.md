🗒️ 설명
---

각 스킬 문서는 작업 시작 전에 공통 규칙 문서를 읽으라고 지시합니다. 예를 들어 이슈를 만들 때는 "이슈 생성 워크플로우 문서를 먼저 따르라", 설정이 필요하면 "설정 규칙 문서를 참조하라"는 식입니다.

그런데 **지시된 경로가 실제 파일 위치와 한 단계 어긋나 있습니다.** 스킬 문서는 `references/...` 라고 적어두는데, 이는 자기 스킬 폴더 안을 가리킵니다. 실제 공용 문서는 스킬 폴더 바깥의 공용 폴더에 있습니다.

```
스킬 문서가 가리키는 곳:  (스킬 폴더)/references/config-rules.md   ❌ 없음
실제 파일이 있는 곳:      (공용 폴더)/references/config-rules.md   ✅ 있음
```

파일이 없는 게 아니라 **경로만 틀린 것**입니다. 그래서 스킬을 실행하면 지시받은 문서를 찾지 못하고, AI는 규정된 절차 대신 임의로 판단해 진행하게 됩니다.

실제로 다른 작업 세션에서 이 문제를 겪었습니다. 이슈를 만들라는 요청에 스킬이 "이슈 생성 워크플로우 문서를 따르라"고 지시했는데 그 문서를 찾지 못해, 저장소의 이슈 템플릿을 직접 읽어 우회했습니다. 결과물은 나왔지만 스킬이 보장하려던 절차(중복 검사, 로컬 저장, 승인 게이트)를 건너뛴 셈입니다.

🔄 재현 방법
---

1. 아무 스킬이나 실행한다
2. 스킬이 "공통 규칙 문서를 먼저 읽으라"고 지시한다
3. 지시된 경로에서 파일을 찾으면 존재하지 않는다
4. AI가 문서 없이 자체 판단으로 진행하거나, 파일을 수동으로 탐색한다

📸 참고 자료
---

**영향 범위**

| 항목 | 수치 |
|---|---|
| 잘못된 경로를 지시하는 스킬 | 16개 |
| 잘못된 참조 위치 | 50곳 |
| 찾지 못하는 공용 문서 | 공통 규칙, 설정 규칙, 이슈 생성 절차, 산출물 경로 규칙, 승인 게이트 기준, 페르소나, 자체검토 기준, 기술별 가이드 등 |

**주의 — 전부 틀린 것은 아니다**

두 스킬은 자기 폴더 안에 **고유한** 참조 문서를 두고 있으며, 그 경로는 정상입니다.

| 스킬 | 자체 참조 문서 | 상태 |
|---|---|---|
| 기록 스킬 | 조사 체크리스트 | 정상 — 자기 폴더에 실재 |
| 스킬 생성 스킬 | 단계별 가이드 7종 | 정상 — 자기 폴더에 실재 |

따라서 수정은 **공용 문서를 가리키는 참조만** 대상이며, 스킬 고유 문서 참조는 그대로 두어야 합니다. 일괄 치환하면 정상인 것까지 깨집니다.

✅ 예상 동작
---

- 스킬 문서가 지시하는 경로를 그대로 따라가면 **파일이 실제로 존재**해야 합니다
- 공용 문서와 스킬 고유 문서가 **구분**되어 각각 올바른 위치를 가리켜야 합니다
- 저장소에서 실행하든 설치본에서 실행하든 동일하게 해석되어야 합니다
- 앞으로 새 스킬을 만들 때 같은 실수가 반복되지 않도록 기준 문서에 규칙이 명시되어야 합니다
