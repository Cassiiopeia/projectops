📝 현재 문제점
---

- projectops의 핵심 진입점은 `npx projectops` CLI인데, README에는 명령 한 줄과 비대화형 예시 하나뿐이다. CLI가 받는 모드(`full`, `workflows`, `skills`, `doctor` 등)와 옵션(`--type`, `--intent`, `--deploy`, `--publish`, `--paths`, `--force` 등), 하위 동작(진단, 업데이트, 수정한 워크플로우 처리)이 README 어디에도 없다. 전체 옵션은 `--help`를 직접 열어 봐야 알 수 있다.
- README가 직관적이지 않다. 처음 온 사람이 "내가 무엇을 하고 싶을 때 무엇을 실행하나"를 바로 찾을 수 없다. 설치 방법이 `빠른 시작`에 흩어져 있고, 20종 스킬 표가 길게 이어져 핵심이 밀린다.

🛠️ 해결 방안 / 제안 기능
---

- 첫 화면 바로 아래에 "30초 시작"을 두고, 하고 싶은 일별로 실행할 명령을 한 표로 보여준다.
- "CLI 사용법" 절을 추가한다. 동작 순서, 모드, 옵션, 예시, 진단(`doctor`) 실제 출력 예, 업데이트 때 알아둘 점을 `--help`와 코드에 있는 사실로만 쓴다.
- 길게 이어지는 스킬 표는 접어서 첫 화면의 밀도를 낮춘다.
- 영어, 중국어, 일본어 번역본에도 같은 구성을 반영한다.
